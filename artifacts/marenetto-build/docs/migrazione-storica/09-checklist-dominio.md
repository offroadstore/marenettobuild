# Checklist del dominio definitivo

- [ ] Riconciliare esportazione dei contenuti pubblicati con il grafo acquisito.
- [ ] Chiudere differenze di struttura, media e metadati, non soltanto testo.
- [ ] Trasferire e verificare tutte le risorse indipendentemente dal vecchio hosting.
- [ ] Confermare diritti e liberatorie senza dedurli dalla vecchia pubblicazione.
- [ ] Approvare le traduzioni pagina per pagina.
- [ ] Verificare canonical e alternati dei soli equivalenti reali.
- [ ] Configurare separatamente l’origine pubblica approvata, mai un URL Replit implicito.
- [ ] Eseguire i controlli dominio/indicizzabilità in un incarico separato con autorizzazione.
- [ ] Preparare monitoraggio Search Console, 404, redirect, canonical e traffico dopo il lancio.

Anteprima sempre noindex/nofollow e robots Disallow: /. Nessun deployment o modifica del dominio eseguiti. Sitemap futura limitata alle edizioni ammissibili, non una dichiarazione di copertura completa.

### Risultato tecnico sulle immagini già consegnate

33 immagini distinte hanno HTTP 200, SHA-256 uguale alla fonte e dimensioni naturali verificate. Il delivery non dipende più dall'hosting storico per gli URL mappati. Questo non chiude diritti, associazioni mancanti o copertura dei materiali non acquisiti.
