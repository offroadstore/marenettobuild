# Matrice degli URL

Vedere matrice-url.csv, una riga per ogni URL osservato, senza dedurre alias da uno slug straniero.

13 URL con redirect osservato sulla fonte; 168 sul nuovo sito. Le catene riportano status iniziale, ogni passaggio e destinazione.

Un 200, una canonicalizzazione dello slash o il solo mantenimento dell'indirizzo non equivalgono a conservazione del testo. Gli ID di contenuto derivano dall'inventario storico; le voci senza corrispondenza usano un identificatore SHA-256 stabile dell'URL, non un'identità editoriale inventata.
